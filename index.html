本政策说明《弹药工坊》如何处理数据，以及您如何管理这些数据。请在使用游戏前阅读；如有疑问，可以通过上述邮箱联系我们。

一、适用范围

本政策适用于由快乐男孩工作室开发的《弹药工坊》Android 2.x（当前更新至 2.7.1） 游戏。下载平台、操作系统、邮件服务和本政策网页的托管服务各自提供的服务，适用其自身的隐私规则。

二、游戏处理的数据

1. 本机存档与设置

为了保存进度和继续游戏，游戏在应用自身的数据目录中保存：瞄准与声音设置、远征进度与种子、路线及奖励选择、实装与预案、蓝图收藏、解锁任务、故事档案和最佳记录。升级时还可能在同一目录保留旧存档及备份，用于迁移和恢复。

这些数据由游戏在您的设备上读写，当前版本不会将其上传至开发者服务器，也不会用于广告画像。开发者无法远程读取、修改或恢复您的本机存档。

2. 改装码与剪贴板

您点击“复制”时，游戏将当前改装码写入系统剪贴板；点击“粘贴”时，游戏读取当时的剪贴板文本并填入导入框，以便解析和预览构筑。仅打开游戏或进入改装界面不会主动读取剪贴板。

改装码用于分享工作台构筑，不包含账号身份信息、邮箱、局内资源或解锁记录。请仅粘贴改装码，避免粘贴密码、验证码等无关内容。您可以选择手动输入，也可以使用系统功能清空剪贴板；游戏不会把剪贴板内容发送给开发者。

3. 您主动发送的反馈

如果您通过邮箱联系我们，我们会收到您的发件地址、邮件正文及您自愿提供的附件。我们仅为答复咨询、处理隐私请求和定位您报告的问题使用这些信息。请勿发送身份证号码、密码或其他与问题无关的敏感信息。

反馈信息保留至问题处理结束后 6 个月内删除，法律另有要求或为处理尚未解决的争议确有必要的除外；您也可以提前申请删除。邮件的传输、存储及服务商自身的处理，适用您所用邮件服务与 QQ 邮箱的相关规则。

三、账号、权限与第三方组件

当前游戏没有账号注册、登录、支付、广告或联网排行榜功能，也未接入广告、行为分析、TapTap 登录等第三方服务 SDK。通过 TapTap 发布安装包，不代表游戏内已经接入 TapSDK。

当前 Android 发布配置未启用互联网及网络状态权限。游戏不申请相机、麦克风、定位、通讯录、短信或外部存储的敏感运行时权限，也不读取这些内容；不收集 IMEI、OAID、Android ID 等设备标识用于统计或追踪。存档使用应用自己的数据目录，无需申请访问您的相册或其他应用文件。

游戏使用 Godot 引擎完成画面、音效、输入和本机文件读写，当前版本未启用通过引擎向开发者传输个人信息的功能。安装、分发及系统备份可能涉及平台或操作系统自身的数据处理，请查阅其隐私说明。

四、共享、转让与公开

当前游戏不会向开发者传输您的存档或剪贴板内容，因此开发者不会将这些内容出售、出租或提供给第三方。

对于您主动发送的反馈，我们只在处理咨询和请求所必要的范围内使用，不会公开您的邮箱或邮件内容。若法律要求提供信息，我们将核实要求并限于必要范围处理；其他向第三方提供或公开个人信息的情形，将依法履行告知和取得同意等义务。

五、保存、安全与删除

本机数据保留至您清除应用数据、删除相关存档，或由操作系统按其规则移除。Android 可在“设置 → 应用 → 弹药工坊 → 存储”中清除应用数据，不同设备的菜单名称可能不同。此操作会删除进度、蓝图、解锁记录和备份，请谨慎操作。卸载、系统备份和恢复的具体行为，以您设备的设置为准。

我们通过应用数据目录隔离、存档备份和完整性校验降低数据损坏风险。请妥善保管设备，避免向他人提供包含个人信息的截图或文件。如发生涉及我们所持反馈信息的安全事件，我们将及时采取补救措施，并依法履行通知义务。

六、您的权利与联系我们

您可以在游戏中查看和修改设置、构筑与蓝图，并通过系统清除本机数据。当前版本没有游戏账号，因此不涉及游戏账号注销。

对于您主动提供给我们的个人信息，您可以申请查阅、复制、更正、补充、删除、撤回相关同意，或要求解释处理规则。请向 3313667903@qq.com 发送主题为“弹药工坊隐私请求”的邮件，说明请求及便于回复的联系方式。我们仅在必要时核实与请求相关的信息，不会要求您提供无关材料，并将在收到请求后 15 个工作日内答复；无法满足请求时会说明原因。

开发者没有本机存档的副本，无法通过邮件代为远程删除或找回；我们可以说明相应的本机操作方式。撤回同意不影响撤回前基于同意进行的处理活动。

七、未成年人保护

未成年人应在监护人的指导下阅读本政策并使用游戏。不满 14 周岁的用户请由监护人协助联系开发者，避免自行通过邮件提供个人信息。我们不会主动要求儿童提供个人信息；如发现未经监护人同意收到儿童个人信息，将及时核实并删除。监护人可以通过上述邮箱提出相关请求。

八、本政策网页

本政策网页由 GitHub Pages 托管，只提供文本阅读和邮件联系入口，没有表单、广告或统计脚本，不主动设置分析或营销 Cookie，也不要求登录。为传输页面和保障服务安全，网页托管及网络服务提供者可能按其规则处理 IP 地址、请求时间及浏览器请求信息；这与游戏内的本机存档相互独立。

九、政策更新

若游戏的数据处理方式、权限或第三方组件发生变化，我们会同步更新本政策、更新日期和游戏内的相应说明，并依法履行告知及取得同意等义务。本政策不将未来尚未实现的功能视为当前已存在的功能。
